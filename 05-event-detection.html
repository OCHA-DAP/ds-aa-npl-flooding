5.3 GEOGloWS Retrospective: RP Exceedance Events

Code 
geoglows_events = {}

for key, station in STATIONS.items():
    rid = station.geoglows_river_id

    # Load retrospective
    retro = pd.read_parquet(DATA_DIR / f"geoglows_retro_daily_{rid}.parquet")
    retro.columns = ["discharge"]

    # Load return periods
    rp = pd.read_parquet(DATA_DIR / f"geoglows_return_periods_{rid}.parquet")
    rp2_threshold = rp.loc[2].values[0]
    rp5_threshold = rp.loc[5].values[0]

    # Trim to DHM data period
    dhm_col = dhm[station.dhm_column].dropna()
    max_date = dhm_col.index.max()
    retro_trimmed = retro[retro.index <= max_date.tz_localize("UTC")]

    # Find RP2 exceedance days
    rp2_exceed = retro_trimmed[retro_trimmed["discharge"] > rp2_threshold]
    rp5_exceed = retro_trimmed[retro_trimmed["discharge"] > rp5_threshold]

    geoglows_events[key] = {
        "rp2_dates": rp2_exceed.index,
        "rp5_dates": rp5_exceed.index,
        "rp2_threshold": rp2_threshold,
        "rp5_threshold": rp5_threshold,
    }

    print(f"\n{station.name}:")
    print(f"  RP2 threshold: {rp2_threshold:,.0f} m³/s → "
          f"{len(rp2_exceed)} exceedance days")
    print(f"  RP5 threshold: {rp5_threshold:,.0f} m³/s → "
          f"{len(rp5_exceed)} exceedance days")

5.4 Event Matching: GEOGloWS vs DHM

Match GEOGloWS RP exceedance events against DHM danger level crossings using a ±7 day window.

Code 
# Get unique event dates (collapse consecutive exceedance days into events)
def collapse_to_events(dates, gap_days=7):
    """Collapse consecutive/nearby dates into distinct events."""
    if len(dates) == 0:
        return pd.DatetimeIndex([])
    dates = dates.sort_values()
    events = [dates[0]]
    for d in dates[1:]:
        if (d - events[-1]).days > gap_days:
            events.append(d)
    return pd.DatetimeIndex(events)


results_rows = []

for key, station in STATIONS.items():
    dhm_dates = dhm_crossings[key]
    geo_ev = geoglows_events[key]

    for rp_level, date_key in [(2, "rp2_dates"), (5, "rp5_dates")]:
        # Collapse consecutive exceedance days into events
        geo_event_dates = collapse_to_events(geo_ev[date_key])

        # Strip timezone for matching
        geo_event_dates_naive = geo_event_dates.tz_localize(None)

        result = match_events(
            source_events=geo_event_dates_naive,
            reference_events=dhm_dates,
            window_days=7,
        )

        results_rows.append({
            "Station": station.name,
            "RP Level": f"RP{rp_level}",
            "DHM Events": result["n_reference"],
            "GEOGloWS Events": result["n_source"],
            "Matched (±7d)": result["n_matched"],
            "DHM Only": len(result["reference_only"]),
            "GEOGloWS Only": len(result["source_only"]),
        })

geoglows_results = pd.DataFrame(results_rows)

5.7 Discussion

Key observations from the event matching:

  1. GloFAS at RP2 had extremely high false alarm rates — 33 false alarms at Chatara, 95 at Chisapani. The GloFAS RP2 thresholds appear too low relative to DHM danger levels.

  2. GEOGloWS RP2 thresholds are much higher (14,459 vs 8,113 m³/s at Chatara), which should produce fewer false alarms — but potentially at the cost of missed events.

  3. The fundamental challenge is that DHM measures water level (meters) while models produce discharge (m³/s). Without a rating curve, the comparison is indirect: we’re checking whether the model’s “extreme event” aligns with the observed “extreme event,” not whether the magnitudes match.
